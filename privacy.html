Privacy policy

Last updated 13 September 2026.

Who this covers

Ugly Notetaker is a personal tool used by one person, its owner. It is not offered to the public and has no other users.

What Google data it uses

Google Drive (drive.file scope). The app writes encrypted backup files into the owner's own Google Drive and reads back only the files it created. It cannot see any other file in that Drive.

Google Calendar (read only). The app reads event titles, times and attendees from the owner's own calendar, so a recorded conversation can be matched to the meeting it belongs to.

How that data is handled

Google data stays on the owner's own server. It is not sold, not shared with third parties, and not used for advertising, profiling or training. Backups are encrypted before they leave the server, so the copy stored in Drive cannot be read by anyone without the owner's key.

Google user data is never transferred to others except as needed to run the tool for its owner, and never for any other purpose. Use of Google APIs conforms to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Calendar data is kept only while the matching conversation is kept. Backups age out on a rolling schedule of about three months. Access can be revoked at any time from the owner's Google account permissions page, and the stored data deleted from the server on request.
